# 🎬 Cartoonia

Scrivi una storia, ottieni un cartone animato: voci, musica, regia, 16 stili del film e un regista IA che gira sul dispositivo. App (PWA) di EssentialApp, funziona offline.

**Apri l'app:** https://essentialapp-2026.github.io/Cartoonia/

- `index.html` – l'app completa (voce «Paola» compresa)
- `ia/` – motori del regista IA: WebLLM (scheda grafica) e wllama (processore); i modelli Qwen 2.5 si scaricano a parte la prima volta
- `manifest.webmanifest`, `sw.js`, `icon-*.png`, `screenshot-*.jpg` – installazione e uso offline
- `LEGGIMI.txt`, `COME INSTALLARE.txt` – novità e istruzioni
- `licenze/` – licenze dei componenti inclusi
